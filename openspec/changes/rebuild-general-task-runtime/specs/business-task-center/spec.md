## ADDED Requirements

### Requirement: 任务中心提供通用任务详情
任务中心 MUST 通过通用任务 API 返回任务策略快照、当前执行次数、最大重试次数、下次重试时间、超时、进度和全部 attempt 摘要，不得由 route 直接拼装任务内部表。

#### Scenario: 查看自动重试任务
- **WHEN** 授权用户打开正在等待第二次重试的任务
- **THEN** 系统展示 retrying 状态、已执行次数、最大重试次数、下次执行时间和已有 attempt 结果

## MODIFIED Requirements

### Requirement: 文档任务提供业务详情
任务中心 MUST 为文档处理任务提供文件与文档版本信息、任务类型、业务执行序号、阶段时间线、通用 attempt 历史、处理结果和错误摘要。技术日志只能作为具有权限用户的次级信息。

#### Scenario: 查看失败任务
- **WHEN** 用户打开失败的文档内容任务
- **THEN** 系统展示失败阶段、稳定错误信息、阶段历史、自动 attempt 历史以及是否允许人工重试

### Requirement: 系统任务保留查询与日志
任务中心 MUST 保留系统任务的分页列表、状态统计、通用详情和权限受控日志查询。日志响应 MUST 返回时间、级别和 attempt，界面与接口 MUST 避免泄露密钥、完整文件内容或长期对象存储地址。

#### Scenario: 查看系统任务日志
- **WHEN** 具有日志权限的管理员请求系统任务日志
- **THEN** 系统返回按时间排列且包含日志级别和 attempt 的脱敏日志
